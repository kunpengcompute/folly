## 版本更新说明

### V1.0.0

**新增特性**

|特性描述|更新说明|
|--|--|
|新增folly io_uring优化补丁仓|基于folly框架，针对网络异步io进行io_uring的优化。本方案采用混合模式，即读操作使用io_uring的multishot模式以减少系统调用，而写操作回退到使用原生send系统调用，以规避io_uring在保序场景下可能引入的延迟。|
